## 真实跑中发现并修复的问题

1. **LLM 模型不可用**:`gpt-5.4` 在该 key 的 "Codex" 分组返回 "not supported when using Codex with a ChatGPT account"(间歇性,因代理多通道负载均衡)。实测 7 个候选,仅 **gpt-5.5 3/3 可靠**,已切换(.env)。
2. **chat() 无重试**:代理对 gpt-5.x 有瞬时 503"资源不足",而 `chat()`(S3 用)原先无重试(与 structured 不对称)。已补 429/5xx 重试、400 立即抛(commit)。

## 遗留观察(第 2 期)

- **性能**:30.7 分钟 > PRD 15 分钟目标(那是 3 分钟片的指标)。S4 逐页串行、gpt-image-2 ~2.4 分钟/页是瓶颈。→ M2:S4 页面并行生成,或换更快图像模型。
