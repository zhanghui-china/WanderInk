## 决策

**GO。** "连环画"产品形态在技术上成立,**不需要**降级到 PRD §8 的"插画+有声书"兜底形态。角色跨页一致性 = 三视图参考 + 固定画风前缀 + 特征 prompt 片段,这条路验证有效。

三个画风均通过,均确认 PRD §8 假设:符号化/绘本风比写实风更能掩盖漂移(靠高对比剪影+色块+道具锚定身份,而非易漂移的精细面部)。

**默认画风:`guofeng_ink`(国风水墨)。** 用户选定(2026-07-08):三者一致性同为 100%,国风水墨画风页间最稳、最贴景区传说题材。`Project.style_preset` 默认值与 CLI `--style` 默认值均设为 `guofeng_ink`。用户后续可随时切换。

## 对 M1 的具体指示

1. **参考图必须缩图后上传(硬要求,影响 Task 14 S4)。** 真实代理上,`/images/edits` 上传两张全尺寸三视图(各 ~1.5MB)multipart 反复 `WriteTimeout`。缩到 768px 最长边后彻底解决,且不损一致性(参考图只需传递角色特征)。→ **T14/S3 用三视图当参考图前,先缩到 ~768px。**

2. **场景泄漏(影响 Task 14 S4,需在 T18 端到端观察)。** spike 每页都把全部角色三视图当参考图传,导致单人场景里模型硬塞进另一个角色(3/3 单人页都发生,所幸塞进来的也 on-model,故一致性不失分)。**真实 S4(T14)按计划只传 `cell.characters` 里的角色三视图,已从设计上缓解**;仍需在 T18 端到端验证单人页不越权出现他人。

3. **provider url 回退修复是这个代理的前提(commit 96c2609)。** `/images/generations` 同时返回空 `b64_json` 和有效 `url`,`_decode` 需非空判断回退 url。

4. **画风一致性是软风险(kids_picture_book)。** 儿童绘本第 5–6 页从扁平水彩漂移到日系厚涂——角色身份一致,但页间渲染风格不统一。国风水墨、现代插画的画风更稳。这不阻塞门禁,但选默认画风时可纳入考量。
