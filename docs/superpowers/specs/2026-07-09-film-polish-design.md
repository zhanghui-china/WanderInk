## 项 1 · 故事节奏框架(改 `s1_script.py`,轻量;`s2_storyboard.py` 轻提示)

**目标**:改编出的剧本引人入胜,不平铺直叙。纯 prompt 强化,不改 schema。

**`s1_script.py` 的 SYSTEM prompt 增补以下叙事框架指令**(在现有规则基础上追加,保留"不魔改结局/儿童向规避暴恐/字数命中"):
- **冷开场钩子**:开篇(第一幕第一场)用悬念、冲突或强画面抓住观众,可勾连景区意象(如"这座塔下,压着一段千年往事…");禁止平铺直叙的背景交代式开头。
- **起承转合**:整体遵循 起(setup)→承(发展)→转(转折/高潮)→合(收束)四段式;张力逐幕递增,高潮置于后段。
- **情感落点**:结尾给出清晰的情感收束(温情/怅惘/释然),呼应主题句。

**`s2_storyboard.py` 的 SYSTEM prompt 加一句轻提示**:
- 每页 caption 顺势在页尾留一点悬念或期待感(承上启下),避免每页都平淡收尾;但不得牺牲"连起来能独立讲通故事"这一硬约束。

**测试**:`test_s1.py` 加断言 SYSTEM 含关键框架词(冷开场/钩子、起承转合、高潮);`test_s2.py` 加断言含页尾悬念提示。均为 prompt 关键词断言,不发真实请求(沿用 respx mock 既有用例结构)。

**不改**:Script schema、run() 逻辑、WORD_TARGETS、字数约束。

## 项 2 · 图片统一为满幅 16:9(改 `typeset.py`;`s4_pages.py` 加构图提示)

**目标**:每页画面同大小、同形状——居中裁切铺满整个 1920×1080,消除竖横不一与死黑边。

**`typeset.py` compose_page 重构**:
- 用 cover-crop 把画面填满整个 `FRAME`(1920×1080):按 `max(1920/w, 1080/h)` 缩放后居中裁切;**裁切锚点垂直方向偏上**(取上约 40% 处而非正中),优先保住人物头部,裁掉的主要是下方(脚部)——因当前多为竖图。已有 `_cover` 辅助函数改造为支持垂直锚点参数。
- 文案从"底部 160px 独立黑条(画面被压在上方 920px)"改为**画面底部的半透明渐变字幕**:画面满幅铺满,底部叠一层从透明到半透明黑的**渐变遮罩**(约 240px 高,越往下越暗),白字带描边居中,压在渐变上保证可读。文案不再占用独立区域、不切走画面。
- 水印保持右上角、带深色描边。
- 保留 `_wrap` 按字宽换行、≤2 行;`title_card`/`credits_card` 不变(仍纯黑底文字卡)。
- **接口不变**:`compose_page(art: bytes, caption: str, out: Path) -> None`,输出仍 1920×1080(项 3 依赖此签名与尺寸,不得改)。

**`s4_pages.py` PAGE_TMPL 增补构图提示**:
- prompt 追加"横向宽幅构图(16:9 横图),主体居中、上下留出安全边距",引导模型多出横图、减少裁切损失。保留"不要出现任何文字"与角色一致性约束。

**测试**:`test_typeset.py`——竖图输入下,输出 1920×1080 且**无死黑边**(四角/边缘为画面内容非纯黑)、字幕区文字像素可辨(非纯黑遮罩下有白字);横图输入亦满幅。`test_s4.py` 若断言 PAGE_TMPL 内容,保持"不要出现任何文字"断言不破。

## 项 3 · Ken Burns + 交叉溶解过渡(改 `ffmpeg.py` + `s6_compose.py`)

**目标**:静止画面加缓慢运动、页间平滑溶解不过黑;时长仍跟语音。三项里最复杂。

**Ken Burns(每页缓慢推拉)**:
- 每页静图(已是 1920×1080 满幅)用 `zoompan` 做缓慢缩放:如 zoom 从 1.0 线性到 ~1.08,输出 1920×1080,时长 = 该页时长(语音 + 0.5s 缓冲)。
- 交替推近/拉远(奇偶页不同方向)增加变化,避免单调。

**交叉溶解(页间)**:
- 页间用 `xfade` 溶解过渡(transition=fade/dissolve,时长 T≈0.5s),取代现有"淡入淡出到黑 + concat"。
- **T 落在每页尾部 0.5s 缓冲的静音处**,使解说不重叠。
- 音频用 `acrossfade`(时长 T)或在缓冲静音处拼接,保证 narration 不交叠。
- 片头卡、片尾卡纳入同一条溶解链(片头→第1页、末页→片尾同样 xfade)。

**实现要点**:
- `ffmpeg.py` 把现有 `page_clip_cmd` + `concat_cmd` 重构为面向 filter_complex 的构建:
  - 可保留"每页先渲染带 zoompan 的中间 clip"再"用一条 xfade 链把所有 clip 串起来(累积 offset:offset_k = Σd_i - (k+1)·T)",或一次性 filter_complex 生成。选实现者认为最稳的方案,但**命令构建函数须返回 list[str] 便于单测**,offset 计算须有单测覆盖。
  - 最终 `loudnorm=I=-16:TP=-1.5:LRA=11` 与 BGM 混音(`finalize_cmd`)保留;若结构变动,等价保留 -16 LUFS 与可选 BGM。
- `s6_compose.py` 改用新的构建方式;仍跳过 status≠confirmed / 缺产物页;片头(景区名+故事名)、片尾(来源+AI 标识)不变。

**测试**:`test_ffmpeg.py`——命令/filter_complex 含 `zoompan` 与 `xfade`;offset 计算正确(给定各页时长与 T,验证累积 offset);silent 分支仍无缓冲(项目既有约定);`test_s6.py`——mock ffmpeg.sh,验证串起片头+页+片尾、跳过失败页、写 output/标 done。真实 ffmpeg 冒烟(环境有 ffmpeg 时)出一小段确认可播放。
