## 一、系统概述

WanderInk Web 系统是一个景区传说有声连环画生成器的可视化操作平台。用户只需输入景区名，系统自动完成传说检索、剧本改编、分镜设计、角色设定、漫画页生成、配音配乐和视频合成，最终产出可播放、可分享的有声连环画视频。

### 1.1 系统特性

- **端到端自动管线**：S0～S6 七个步骤全自动完成，无需手动切换工具
- **分步可干预**：每步输出可视化预览，支持修改剧本、调整分镜、重绘页面、重配音
- **断点续跑**：基于 `project.json` 的断点续跑机制，只填充缺失部分
- **多用户协作**：支持团队成员共享项目，查看他人作品进度
- **配置灵活**：支持全局默认和按环节覆盖的模型/端点配置

### 1.2 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    前端 (React + Vite + Tailwind)            │
│  登录 / 新建项目 / 队列监控 / 作品详情 / 配置面板             │
├─────────────────────────────────────────────────────────────┤
│                    后端 (FastAPI + Pydantic)                │
│  API 网关 / 管线编排 / 断点续跑 / 权限控制                   │
├─────────────────────────────────────────────────────────────┤
│                    Provider 层                              │
│  LLM / Image / TTS / Music (OpenAI 兼容)                    │
├─────────────────────────────────────────────────────────────┤
│                    模型服务                                  │
│  Hermes Agent / ComfyUI / Qwen-TTS / ACE-STEP              │
└─────────────────────────────────────────────────────────────┘
```

## 二、登录与退出

### 2.1 登录页面

打开 Web 地址后，首先进入登录页面：

- **用户名输入框**：输入管理员分配的用户名
- **密码输入框**：输入对应密码（密码以密文形式显示）
- **登录按钮**：点击后验证身份，验证通过后跳转到主界面
- **错误提示**：登录失败时显示红色错误信息

> **注意**：系统不支持自助注册，新增账号需联系管理员在服务器上创建。

### 2.2 退出系统

登录后，顶栏右侧显示当前用户名和"退出"按钮：

1. 点击顶栏右侧的"退出"链接
2. 系统清除会话并返回登录页面

## 四、新建作品

### 4.1 表单字段说明

在左侧"新建作品"卡片中填写以下字段：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 景区名 | 文本输入 | 是 | - | 如"雷峰塔""黄鹤楼"，支持快捷选择按钮 |
| 时长(分钟) | 下拉选择 | 是 | 3 | 可选：1 / 3 / 5，决定剧本目标字数与成片长度 |
| 受众 | 下拉选择 | 是 | 大众 | 可选：儿童 / 大众；儿童向会自动规避暴力恐怖细节 |
| 基调 | 下拉选择 | 是 | 温情 | 可选：温情 / 奇幻 / 悬疑 |
| 画风 | 下拉选择 | 是 | 国风水墨 | 可选：国风水墨 / 儿童绘本 / 现代插画 |
| 音色 | 下拉选择 | 否 | 默认 | 留空使用默认音色 |
| 语速 | 下拉选择 | 是 | 1.0 | 可选：0.8 / 1.0 / 1.2 |
| 启用分格排版 | 复选框 | 否 | 关闭 | 开启后使用日式多格漫画排版 |
| 使用编剧/导演大师skill | 复选框 | 否 | 关闭 | 开启后走 hermes-agent 的编剧/导演技能生成剧本和分镜 |
| 自备故事 | 文本域 | 否 | 留空 | 留空则系统自动检索传说；填了就跳过检索，直接基于这段文本改编 |

### 4.2 快捷选择

景区名字段下方提供常见景区的快捷按钮：
- 雷峰塔
- 黄鹤楼
- 莫高窟
- 峨眉山

点击任意按钮即可快速填充景区名字段。

### 4.3 提交生成

1. 填写完整表单后，点击"开始生成"按钮
2. 按钮变为"提交中…"状态，等待系统响应
3. 提交成功后，作品自动进入"生成队列"
4. 系统后台自动执行 S0～S6 完整管线

> **注意**：如果景区传说涉及敏感话题（如近现代政治人物），系统会自动过滤并报错，此时可以使用"自备故事"路径生成。

## 五、生成队列

### 5.1 队列显示

"生成队列"卡片实时显示当前正在排队/生成中的所有作品：

| 信息项 | 说明 |
|---|---|
| 动画条 | 红色闪烁条表示正在生成中 |
| 景区名 | 显示作品对应的景区名称 |
| 项目ID | 显示项目ID前8位 |
| 所有者 | 显示创建作品的用户名 |
| 状态 | 显示 queued（排队中）或 running（生成中） |

### 5.2 队列操作

| 操作 | 条件 | 说明 |
|---|---|---|
| 点击跳转 | 任何状态 | 点击队列项跳转到对应作品详情页查看进度 |
| 取消任务 | 自己创建的任务，状态为 queued 或 running | 点击"取消"按钮取消任务，取消后任务状态变为 error |

> **注意**：任务一旦完成或出错，"取消"按钮会自动隐藏。

### 5.3 队列刷新

队列面板每 3 秒自动刷新一次，确保显示最新状态。

## 六、作品列表

### 6.1 列表显示

"作品列表"展示所有历史作品，每条包含：

| 信息项 | 说明 |
|---|---|
| 景区名 | 作品对应的景区名称 |
| 所有者 | 显示创建作品的用户名 |
| 项目ID | 显示完整的项目ID |
| 状态徽章 | 显示作品当前状态 |

### 6.2 状态徽章说明

| 徽章 | 样式 | 含义 |
|---|---|---|
| 已完成 | 绿色背景 | 全部页面都成功出图+真人解说，视频完整 |
| 已完成·降级 | 金色背景 | 视频已合成，但部分页因生成失败被跳过或只有静音兜底 |
| 生成中 | 金色背景 | 正在排队或跑管线 |
| 待合成 | 灰色背景 | 内容已齐备但还没合成成片（通常是单步重跑了 S2～S5 之后） |
| 出错 | 红色背景 | 某一步失败，点进详情看具体原因 |

### 6.3 列表操作

| 操作 | 条件 | 说明 |
|---|---|---|
| 点击查看 | 任何状态 | 点击列表项进入作品详情页 |
| 删除作品 | 管理员权限 | 点击"×"按钮删除作品，需二次确认 |

## 七、作品详情页

### 7.1 顶部信息区

作品详情页顶部显示：

| 元素 | 说明 |
|---|---|
| 景区名首字徽章 | 展示景区名第一个字，配有印章装饰 |
| 作品标题 | 显示剧本标题（若无则显示景区名） |
| 参数摘要 | 显示画风、时长、受众、基调 |
| 复制链接按钮 | 复制当前作品的可分享 URL（含 `?project=<id>`） |

### 7.2 生成进度

"生成进度"卡片按 S0～S6 顺序显示每个环节的状态：

| 步骤 | 名称 | 说明 |
|---|---|---|
| S0 | 传说 | 检索景区相关传说 |
| S1 | 剧本 | 改编剧本 |
| S2 | 分镜 | 设计分镜表 |
| S3 | 角色 | 角色设定与三视图 |
| S4 | 漫画页 | 逐页生成漫画 |
| S5 | 配音 | 配音与背景音乐 |
| S6 | 合成 | 合成最终视频 |

进度卡片还显示：
- 每步右侧显示该环节耗时
- 鼠标悬停显示具体开始/结束时刻（本地时区）
- 顶部显示总进度（N/7 环节）和总耗时
- S4（漫画页）作为当前步时，额外显示"已出图 N/M 页"细粒度进度

### 7.3 成片播放与导出

管线跑完后，详情页顶部显示视频播放器和导出按钮：

| 按钮 | 功能 |
|---|---|
| 下载完整成片 | 下载 MP4 视频文件 |
| 下载 PDF | 导出图文版 PDF（首次点击会现场打包） |
| 下载图片包 | 导出全部页面图片的 ZIP 包（首次点击会现场打包） |

### 7.4 人物设定·三视图

展示每个角色的三视图（正/侧/背面像），每张卡片支持：

| 操作 | 说明 |
|---|---|
| 查看详情 | 点开大图查看三视图 |
| 重绘设定图 | 对角色三视图不满意时重新生成 |

> **重要**：重绘角色设定图后，不会自动重新画已经用到该角色的连环画页，需要手动去对应页面点击"重绘"或使用"角色"步骤按钮重新触发。

### 7.5 连环画·逐页

每一页显示画面、字幕文案、情绪标签和音频播放条（如已配音）。

#### 7.5.1 页面状态标识

| 标识 | 含义 |
|---|---|
| 生成失败 | 页面标红显示，生图未成功 |
| 静音兜底 | TTS 失败后用估算时长生成了无声音轨 |
| 情绪标签 | 温情/惊变/悲壮/险境/烟雨/苍凉等，用不同颜色区分 |

#### 7.5.2 编辑操作（仅当作品不在生成中且非只读模式时可用）

| 操作 | 说明 |
|---|---|
| 改字面 | 点击编辑图标，修改文案/画面描述/情绪/出场角色后保存，不会重新生成图片和音频 |
| 重绘 | 重新生成该页图片，会调用配置的生图 API |
| 重配音 | 重新合成该页的解说音频 |
| 插入页 | 在当前页前/后插入新的空白页，填好文案后单独生成 |
| 删除页 | 删除该页（不可撤销） |
| 拖拽排序 | 拖动页面卡片调整顺序 |

### 7.6 补全重生成（单步重跑）

详情页中部有一排单步重跑按钮：

| 按钮 | 说明 |
|---|---|
| 分镜 | 重新执行 S2，会清空后续所有步骤产物（标红警示） |
| 角色 | 重新执行 S3，生成角色三视图 |
| 漫画页 | 重新执行 S4，生成漫画页面 |
| 配音 | 重新执行 S5，生成配音和背景音乐 |
| 合成 | 重新执行 S6，合成最终视频 |

**前置条件**：
- 剧本未生成完时，分镜/角色按钮置灰
- 无分镜页面时，漫画页/配音/合成按钮置灰
- 右侧显示"N 页待重生成"提示，提醒用户哪些页还需要处理

### 7.7 传说来源

页面底部展示作品所用传说的详细信息：

| 信息项 | 说明 |
|---|---|
| 标题 | 传说名称 |
| 来源类型 | 正史/地方志/民间传说/文学作品/原创演绎 |
| 梗概 | 传说内容摘要 |

## 八、配置面板

### 8.1 打开方式

点击顶栏右侧的齿轮图标 ⚙，打开"端点与模型配置"面板。

### 8.2 全局默认配置

全局默认配置包含四组 Provider 设置：

| 分组 | 配置项 |
|---|---|
| LLM(文本生成) | 端点 Base URL、API Key、模型、Provider、超时(秒) |
| 图像生成 | 端点 Base URL、API Key、模型、API 模式、图片尺寸、LoRA 模型 |
| 语音合成 | 端点 Base URL、API Key、模型、默认音色、可选音色(逗号分隔) |
| 背景音乐 | 端点 Base URL、API Key、模型 |

### 8.3 按环节覆盖

展开"按环节覆盖"可对 S0～S5 各环节单独指定不同的端点/模型：

- 不填则继承全局默认配置
- 填了则覆盖该环节的全局默认值
- 支持为不同环节配置不同的模型（如 S1～S2 使用 Hermes，S4 使用本地 ComfyUI）

### 8.4 配置操作

| 操作 | 说明 |
|---|---|
| 修改配置 | 在输入框中修改对应字段 |
| 清除配置 | 点击"清除(改为继承)"按钮将字段恢复为继承状态 |
| 保存配置 | 点击"保存"按钮立即生效，无需重启服务 |

> **注意**：只读模式下配置面板只能浏览，不能保存。

### 8.5 密钥字段语义

| 状态 | 含义 |
|---|---|
| 已配置 | 显示"已配置 · 留空不变"，留空提交时保持原值 |
| 空值 | 显示"将清除 · 保存后继承"，提交后清除并继承上级配置 |
| `__UNCHANGED__` | 哨兵值，表示不改动（后端内部使用） |

## 九、分享功能

### 9.1 分享链接

每个作品都有唯一的分享 URL：

1. 在作品详情页点击"复制链接"按钮
2. 链接被复制到剪贴板（显示"已复制"提示）
3. 将链接发给团队其他成员

### 9.2 URL 格式

```
https://your-domain.com/?project=<project_id>
```

## 十、常见问题

### 10.1 作品显示"已完成·降级"是什么意思？

视频已经能播放，但不是每一页都成功生成：
- 可能是部分页生图失败被跳过（显示"N/M 页出图"）
- 也可能是部分页 TTS 失败使用了静音兜底（显示"N 页静音兜底"）

**解决方法**：回到详情页对失败的页点击"重绘"/"重配音"，或使用"补全重生成"里的对应步骤按钮重跑。

### 10.2 点击"重绘"没反应或等待时间过长？

- 点击后会弹出确认框，确认后按钮显示"重绘中…"
- 随后顶部显示"正在生成…"全局状态
- 生图步骤比较慢（远程 API 可能需要几十秒到几分钟一页），请耐心等待，不要重复点击

### 10.3 为什么某个景区检索不到传说？

- 可能是该景区确实没有可靠出处的传说
- 也可能是候选传说涉及敏感话题被系统过滤

**解决方法**：使用"自备故事"路径，自己写一段故事文本生成。

### 10.4 队列里的任务属于谁？

- 队列显示创建作品的登录用户名
- 只有自己创建的任务才能取消
- 其他人的任务只能查看不能操作

### 10.5 如何取消正在生成的任务？

- 在"生成队列"中找到自己的任务
- 点击"取消"按钮
- 取消后任务状态变为 error，可以重新生成

### 10.6 如何导出作品？

- 在作品详情页顶部，成片播放器下方
- 点击"下载完整成片"下载 MP4 视频
- 点击"下载 PDF"导出图文版 PDF
- 点击"下载图片包"导出全部页面图片的 ZIP 包

### 10.7 为什么导出按钮显示"打包中…"？

首次点击导出按钮时，系统会现场打包文件，打包完成后按钮变成可直接下载的链接。

### 10.8 如何修改已生成的剧本或分镜？

- 在漫画页列表中点击编辑图标 ✎
- 修改画面描述、旁白文案、情绪标签、出场角色
- 保存后不会重新生成图片和音频，如需重新生成请使用"重绘"或"重配音"功能

### 10.9 如何调整页面顺序？

- 直接拖动页面卡片到目标位置
- 拖动时页面边框变为红色，放置后自动保存新顺序

### 10.10 如何插入新页面？

- 在目标页面下方点击"+ 插入下一页"按钮
- 填写画面描述和旁白文案
- 点击"确定插入"创建新页面
- 新页面需要单独点击"重绘"生成图片

## 十一、安全提示

### 11.1 AI 内容标识

每个成片右上角都会烧录半透明水印"本视频由 AI 辅助生成"，片尾字幕卡也会有文字说明，这是固定行为，不可关闭。

### 11.2 敏感内容过滤

系统会自动过滤涉及以下内容的传说：
- 真实近现代政治人物
- 敏感历史事件
- 宗教极端内容
- 暴力恐怖元素（儿童向）

### 11.3 版权说明

- 用户上传自定义故事时需自行确保拥有相应权利
- 系统输出的作品会明确标注来源和 AI 生成身份
