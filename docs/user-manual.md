# WanderInk(墨拾遗)用户操作手册

> 景区传说有声连环画生成器——输入一个景区名,自动检索历史传说、改编剧本、设计角色、逐页绘制连环画、配音配乐,最终产出一部可播放、可分享的有声连环画视频。
>
> 本手册面向**日常使用者**(团队内部访问 Web 界面生成/编辑作品),不涉及部署运维(运维见 `docs/deploy-dgx.md`)。

---

## 1. 登录

打开 Web 地址后会先看到登录页,输入管理员分配的用户名/密码登录。本系统不支持自助注册,新增账号需请管理员在服务器上创建。

登录后顶栏右侧显示当前用户名和"退出"按钮。

---

## 2. 整体界面

登录后是两栏布局:

- **左侧**:新建作品表单 → 生成队列 → 作品列表(从上到下)
- **右侧**:选中作品的详情(未选中任何作品时显示引导提示)

顶栏右上角有一个齿轮图标 ⚙,点开是**端点与模型配置面板**(见第 8 节),多为项目负责人使用。

---

## 3. 新建作品

在左侧"新建作品"卡片里填写:

| 字段 | 说明 |
|---|---|
| 景区名 | 必填,如"雷峰塔""黄鹤楼";下方有几个常见景区的快捷按钮 |
| 时长(分钟) | 1 / 3 / 5,决定剧本目标字数与成片长度 |
| 受众 | 儿童 / 大众;儿童向会自动规避暴力恐怖细节 |
| 基调 | 温情 / 奇幻 / 悬疑 |
| 画风 | 国风水墨 / 儿童绘本 / 现代插画 |
| 音色 | 可选,留空用默认音色 |
| 语速 | 0.8 / 1.0 / 1.2 |
| 启用分格排版(日式分镜) | 开启后连环画页会用多格漫画排版,而不是单图一页 |
| 用"编剧大师"生成剧本/分镜 | 默认开启,走 hermes-agent 的编剧 skill 生成剧本;关闭则用系统默认配置的 LLM(如本地 Ollama)直接生成,不依赖该 skill |
| 自备故事(可选) | 留空则系统自动检索传说;填了就跳过检索,直接基于这段文本改编 |

点击"开始生成"后立即返回,作品进入"生成队列",无需等待——可以继续浏览其它作品,后台会一路跑完 S0→S6 六个环节。

**内容安全提示**:如果这个景区的传说涉及真实近现代政治人物/事件(如某段历史事件牵涉到具体国家领导人),系统会自动过滤掉这类候选传说或直接报错阻止生成;此时可以换一个角度自己写一段"自备故事"再试。

---

## 4. 生成队列

"生成队列"卡片实时显示当前正在排队/生成中的所有作品(所有团队成员的都能看到,只是名字不同)。点击某一项可以跳转到它的详情页查看进度。

自己的任务在"排队中"或"生成中"时,右侧会出现"取消"按钮;任务一旦完成/出错就不再显示这个按钮(点了也没意义,后端会直接拒绝)。

队列为空时这块区域不显示。

---

## 5. 作品列表

左侧"作品列表"展示所有历史作品,每条右侧有状态徽章:

| 徽章 | 含义 |
|---|---|
| 已完成 | 全部页面都成功出图+真人解说,视频完整 |
| 已完成·降级 | 视频已合成,但部分页因生成失败被跳过,或部分页只有静音兜底(无真人解说)——点进详情能看到具体降级说明 |
| 生成中 | 正在排队或跑管线 |
| 待合成 | 内容已齐备但还没合成成片(通常是单步重跑了 S2–S5 之后) |
| 出错 | 某一步失败,点进详情看具体原因 |

点击任意一条进入详情页。

---

## 6. 作品详情页

### 6.1 顶部信息与分享

标题栏显示景区名、参数摘要;右上角"复制链接"按钮会把当前作品的可分享 URL(形如 `?project=<id>`)复制到剪贴板,发给团队其他人打开就能直接看到同一个作品。**对方需要有账号并已登录**——链接不是公开的。

> **哪些能互相看、哪些不能**
> 作品本身(成片、漫画页、分镜文案、配音、导出的 PDF/图片包)团队内**所有人都能看**,这是有意的设计。
> 但两样**只有作者本人和管理员**能看:
> - **自备故事原文**——展开「故事来源」时,别人的作品只会显示一行说明,看不到你贴的原文
> - **自定义音色的那段录音**——别人的作品上不会出现"当前自定义音色"这颗回听按钮
>
> 另外从 2026-08-06 起,成片、图片这些产物的直链**必须登录才能打开**。把这类链接发给没有账号的人,对方会打不开。

### 6.2 生成进度

"生成进度"卡片按 S0(传说)→S1(剧本)→S2(分镜)→S3(角色)→S4(漫画页)→S5(配音)→S6(合成)顺序列出每个环节:

- 每个环节右侧显示该环节耗时;**鼠标悬停**在某一行上,会弹出该环节的具体开始/结束时刻(本地时区)
- 顶部显示总进度(N/7 环节)和总耗时;全部完成后总耗时不再跳动
- 正在生成时顶部显示"正在生成…"动画;S4(漫画页)是当前步时,还会额外显示"已出图 N/M 页"这种细粒度进度(这一步通常耗时最长)

### 6.3 成片播放与导出

管线跑完、成片(mp4)产出后,详情页顶部会出现视频播放器,下方两个按钮:

- **下载 PDF**:导出图文版 PDF
- **下载图片包**:导出全部页面图片的 zip 包

首次点击会现场打包(按钮显示"打包中…"),打包完成后按钮变成可直接下载的链接。

### 6.4 人物设定 · 三视图

展示该作品用到的每个角色的三视图(正/侧/背面像),每张卡片可以:

- **查看详情**:点开大图
- **重绘设定图**:对某个角色的三视图不满意时用这个——会弹确认框("仅重绘设定图,已生成页面需自行重绘"),确认后该角色解锁重画,但**不会**自动重新画已经用到这个角色的连环画页,需要再单独去对应页面点"重绘"或用下方的"角色"步骤按钮重新触发。

### 6.5 连环画 · 逐页

每一页显示画面、字幕文案、情绪标签,以及(如果已配音)一个音频播放条。可编辑操作(仅当作品不在生成中、且不是只读模式时可用):

| 操作 | 说明 |
|---|---|
| 改字面 | 点开编辑框,修改文案/画面描述/情绪/出场角色后保存,不会重新生成图片和音频 |
| **重绘** | 确认后立即调用配置好的生图 API 重新生成这一页的图片;只会重画标记过的页,不影响其它已成功的页 |
| **重配音** | 重新合成这一页的解说音频 |
| 插入页 | 在某页前/后插入一个新的空白页,填好文案后单独生成 |
| 删除页 | 确认后删除该页(不可撤销) |
| 拖拽排序 | 直接拖动页面卡片调整顺序 |

生成失败的页会标红显示"生成失败";静音兜底的页(TTS 失败后用估算时长生成了无声音轨,保证成片时长完整但没有真人解说)会标"静音兜底"。

### 6.6 补全重生成(单步重跑)

详情页中部有一排按钮:分镜 / 角色 / 漫画页 / 配音 / 合成,用于单独重跑某一步(比如只想重新合成,不想从头再来一遍)。

- 前置条件不满足时按钮会置灰(比如剧本还没生成完,分镜/角色按钮点了也会失败,所以直接禁用)
- "分镜"标红,因为重新执行会清空之后所有步骤的产物,点击会有二次确认
- 右侧"N 页待重生成"提示当前有多少页还没成功出图或配好音,提醒该点哪个按钮补

### 6.7 传说来源

页面底部展示这个作品所用传说的标题、来源类型(正史/地方志/民间传说/文学作品/原创演绎)和梗概,供核实内容真实性。

---

## 7. AI 内容标识

每个成片右上角都会烧录一个半透明水印"本视频由 AI 辅助生成"(透明背景叠加,不遮挡画面主体),片尾字幕卡也会有一行文字说明。这是固定行为,不可关闭。

---

## 8. 端点与模型配置(齿轮图标)

点击顶栏齿轮图标打开配置面板,可以设置:

- **全局默认**:LLM(文本生成)/ 图像生成 / 语音合成 三组端点、密钥、模型
- **按环节覆盖**(展开"▸ 按环节覆盖"):S0–S5 各环节可以单独指定不同的端点/模型(比如某一步走云端强模型,其它步用本地免费模型),不填就继承全局默认

密钥字段留空表示"不改动";已配置的密钥旁边有"清除(改为继承)"按钮可以显式清空。改动后点"保存"立即生效,无需重启服务。

只读模式(公开演示地址)下这个面板只能浏览,不能保存。

这个面板通常由项目负责人使用,一般用户不需要改动。

## 9. 常见问题

**Q:作品显示"已完成·降级"是什么意思?**
A:视频已经能看,但不是每一页都成功了——可能是部分页生图失败被跳过(降级文案会写"N/M 页出图"),也可能是部分页 TTS 失败用了静音兜底("N 页静音兜底")。想补全的话,回到详情页对失败的页点"重绘"/"重配音",或用"补全重生成"里的对应步骤按钮重跑,完成后记得重新点一次"下载 PDF/图片包"刷新导出物(视频会自动更新)。

**Q:点了"重绘"没反应/等了很久?**
A:点击后会有确认框,确认后按钮会短暂显示"重绘中…",随后会转为顶部的"正在生成…"全局状态——生图这一步比较慢(远程 API 可能要几十秒到几分钟一页),耐心等,不要重复点击。

**Q:为什么某个景区检索不到传说?**
A:可能是这个景区确实没有可靠出处的传说,或者候选传说涉及敏感话题被系统过滤了。这种情况下会报错提示"请提供自备故事",可以自己写一段故事文本走"自备故事"路径生成。

**Q:队列里的任务算是谁的?**
A:显示的是创建作品的登录用户名;只有自己创建的任务才能取消,其他人的任务只能查看不能操作。
